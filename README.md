Purpose
UbuntuMentor is an Android application designed to connect South African youth with mentors, career guidance, and verified opportunities. This prototype was built for the OPSC6312 module.

Features Implemented

User Registration and Login (connected to REST API)

Settings Menu with Logout functionality

REST API Integration (Node.js backend fetching Opportunities)

Home Dashboard UI
